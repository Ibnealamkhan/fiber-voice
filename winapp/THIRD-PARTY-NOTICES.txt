Fiber Voice for Windows

The calling engine includes CPython 3.13.16 (PSF License), aiohttp, aiortc,
PyAV/FFmpeg, OpenSSL, libsrtp, and their dependencies. Python's LICENSE.txt and
Python package license files are preserved in the extracted Engine directory
under %LOCALAPPDATA%\Fiber Voice. Exact wheel versions and SHA256 hashes are in
requirements-windows.txt in the source repository.

AMR codecs: OpenCORE AMR 0.1.6 and VisualOn AMR-WB encoder 0.1.3, Apache 2.0.
The Apache license is included in codecs/LICENSE-APACHE-2.0.txt.
Windows codec binaries are MSYS2 UCRT64 packages, SHA256-pinned in prepare_bundle.py.
Upstream source: https://sourceforge.net/projects/opencore-amr/files/
https://github.com/mstorsjo/vo-amrwbenc
MSYS2 build recipes: https://github.com/msys2/MINGW-packages

PyAV/FFmpeg sources and build configuration:
https://github.com/PyAV-Org/PyAV/tree/v19.0.2
https://github.com/PyAV-Org/pyav-wheels
FFmpeg project: https://ffmpeg.org/

The Microsoft WebView2 SDK and runtime bootstrapper are included under their
Microsoft license terms. The runtime installer is obtained from Microsoft's
official distribution endpoint and installs Evergreen WebView2 only if missing.
https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.3650.58
https://developer.microsoft.com/en-us/microsoft-edge/webview2/

Fiber Voice source and license: https://github.com/Ibnealamkhan/fiber-voice
